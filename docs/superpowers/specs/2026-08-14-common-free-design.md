# 公共课余时间查询 — 设计

日期：2026-08-14。Phase 0 已用真实账号登录教务并核对总表页。参考项目 `xu-shu-xitong/` 只读，不修改。

## 意图

把旧系统里能用的「登录教务 → 拉教师总表 → 查多人公共空闲」单拎出来，做成独立的单屏软件。旧系统难用的地方不搬：教师映射、手填学期、七百人下拉、没课表时只有一条黄字。

使用者是自己拿着教务账号查全校老师空闲的人。教务本身不区分查看权限，所以本软件不做登录用户，也不把老师绑到某个账号。

## 目标

- 一次同步按学院拉取该学期全部教师课表，老师自带学院。
- 打开即可查：学期下拉、周次自动定位到当前自然周、顶部输入姓名或拼音首字母秒选老师。
- 选中的一批老师可存成常用分组，下次点胶囊直接查询。
- 结果是 7 天 × 6 大节的热力矩阵。绿=全员空闲，黄=仅 1 人有课，红=多人有课。点格子，右侧抽屉显示谁有课、格子原文是什么。
- 教务没有专业。用「姓名,学院,专业」文本一次贴上，按姓名匹配，不逐个点。

## 非目标

- 不做课表姓名到本系统用户的映射。
- 不做本软件账号、角色、权限。
- 不把密码、Cookie、滑块票据写入数据库、日志或源码。
- 不搬旧系统的成果、AI、组织架构、Excel 三表。导出留到后面，第一阶段不做。
- 不自动猜滑块轨迹。出现滑块时由人滑。

## 反目标

- 没课表时把 42 格显示成空闲。缺数据必须弹窗，只给一个动作：同步这个学期。
- 同步时丢掉未映射老师。新系统没有映射，总表里的老师全部入库。
- 把职称下拉 `jszc` 当成专业。实测那 15 处「专业」全是职称名称。

## Phase 0 实测结论

2026-08-14，探测脚本 `probe/jw-probe.mjs` 只在运行时读取 `.env.local`。`.env.local` 的 `JW_BASE_URL` 实际是统一认证站 `authserver.dgpt.edu.cn`，不是教务站。教务站沿用旧系统已验证的 `jw.dgpt.edu.cn`。本次登录未触发滑块。

登录链：认证页 → 密码 AES-128-CBC（64 位随机前缀 + 页面盐，向量 16 位）→ 302 → 个人中心 → `jw` 的 `/jsxsd/sso.jsp` → `/jsxsd/framework/xsMain.jsp`。总表页 `GET /jsxsd/kbcx/kbxx_teacher` 返回 200，32505 字节。

总表页真实下拉：

| 字段 | 含义 | 实测 |
| --- | --- | --- |
| `xnxqh` | 学期 | 29 项，当前选中 `2026-2027-1`，从 `2011-2012-1` 到 `2029-2030-2` |
| `kbjcmsid` | 节次模式 | 唯一选项「默认节次模式」，值是 32 位十六进制，页面未标 selected。唯一值可用，不能猜成 `0102` |
| `skyx` | 上课院系 | 1 个空项 + 13 个学院。多数值是 32 位十六进制，四个筹备学院是短码 `0100` `0101` `0102` `0104` |
| `jszc` | 职称 | 292 项。不是专业 |
| `zc1` `zc2` | 周次 | 1–30 |
| `skxq1` `skxq2` | 星期 | 1–7 |
| `jc1` `jc2` | 节次 | 只有「请选择」，没有节次项 |
| `skjs` | 教师姓名 | 文本框，不是下拉 |

没有专业、教研室下拉，也没有单独的学院/专业字典接口出现在这个页面。

`POST /jsxsd/kbcx/kbxx_teacher_ifr`，周次 1–30、星期和节次留空：

- `skyx` 为空：766 名教师。
- `skyx` = 智能制造学院：59 名，59 名都在全校名单里，没有名单外的人。

结论：按学院拉取有效。同步时对每个非空 `skyx` 拉一次，入库时把该学院绑到这批老师。不拉空 `skyx` 的全校表，避免一人多学院时无法归属；若某人出现在多个学院，保留多个学院，不覆盖成一个。

课表格子结构与旧解析一致：`#kbtable`，前两行表头，每位教师一行 43 列，第 1 列姓名，后 42 列按 7 天 × `0102,0304,0506,0708,0910,1112`。调课、占位、实验课都算占用。周次取格子原文；写不出来时按 1–30 全周，避免把有课判成空闲。

## 他们定下的行为

- 技术栈：Node + TypeScript + SQLite + Vue 3 单屏。
- 顶部指令栏直接搜姓名或拼音首字母，回车查询。当前选择可存成常用分组胶囊。
- 学院 / 专业 / 表格勾选只放在辅助抽屉，不是主路径。
- 冲突胶囊：全员空闲、仅 1 人忙碌、多人冲突。矩阵格内写状态或冲突人数。抽屉展示该节次有课的人、课程和格子原文。
- 设置里保存「第 1 周周一」。打开时按今天推算当前周，限制在 1–30。没配置就用第 1 周。
- 专业用粘贴文本批量绑定，格式 `姓名,学院,专业`，按姓名匹配。匹配不到的姓名列出来，不中断已匹配的行。

## 留给实现的决定

- 后端用 Fastify。前端用 Vite + Vue 3，不用旧项目的 Element Plus 向导页。
- 拼音首字母用一个小的本地字库在写入教师时算好，查询不再临时算。
- 同步是本地进程内任务，前端用轮询拿进度。不做账号体系，所以接口只监听本机 `127.0.0.1`。
- 教务地址：认证站和教务站分开配置，默认就是这次实测的两个主机。账号密码只来自环境变量或当次输入，不进源码、不进库。
- 滑块：第一阶段若认证要求滑块，接口返回两张图，由界面让人拖动后提交轨迹。不自动识别缺口。
- 学期列表每次打开总表页更新。查询下拉优先用最近一次同步记下的列表；还没有同步过时，用「今年往前 4 年、往后 1 年，每年两个学期」临时生成。
- 同一学期再次同步替换该学期的占用和学院归属，不替换用户粘贴的专业，也不删除常用分组。
- 分组按教师姓名记住成员。老师下一次同步还在，胶囊就能加载。

## 数据

SQLite 文件 `data/app.sqlite`。

- `colleges`：`code` 主键，`name`，`short_code`（标签方括号里的编号，可空）。
- `semesters`：`code` 主键（`2026-2027-1`），`label`，`is_current`。
- `teachers`：`name` 主键，`pinyin_initials`，`title` 可空，`updated_at`。
- `teacher_colleges`：`(teacher_name, college_code)` 联合主键。
- `teacher_programs`：`teacher_name` 主键，`program_name`。只由粘贴维护。
- `occupancies`：自增 `id`，`semester_code`，`teacher_name`，`day_of_week` 1–7，`slot_code`，`week_start`，`week_end`，`occupancy_text`。索引 `(semester_code, teacher_name)`。
- `preset_groups`：`id`，`name` 唯一，`created_at`。
- `preset_group_members`：`(group_id, teacher_name)` 联合主键。
- `settings`：`key` 主键，`value`。第一阶段只用 `week1_monday`，值是 `YYYY-MM-DD`。

没有用户表，没有映射表。

## 界面

单屏三块。

1. 顶部指令栏：学期下拉、周次（已按设置推算）、老师搜索、已选人名胶囊、常用分组胶囊、回车查询。另有两个入口：同步、批量勾选。
2. 同步时顶部下方一张进度卡：当前学院、已完成学院数、已入库教师数。不挡住矩阵，不锁住页面。
3. 矩阵上方三个过滤胶囊，数字是该档的格子数。主体 7×6。点击格子打开右侧抽屉：冲突人数、有课教师、课程名（原文第一行）、格子原文。可复制。

没同步过所选学期：不渲染 42 格，弹窗写「这个学期还没有课表」，按钮是「同步 2026-2027-1」。

批量抽屉：学院、专业（含「未指定」）、可勾选表格、搜索。确认后把勾选合并进指令栏的已选名单。

粘贴专业在同一抽屉的另一页：一个文本框，提交后显示匹配数、未匹配姓名、学院对不上的姓名。学院对不上只警告，不阻止写入专业。

## 失败时给人看的话

- 教务拒绝账号或滑块：停在同步卡，密码留在内存输入框，不清空。
- 教务没有返回教师行：该学院记失败，已成功的学院保留；整次同步最后报「哪些学院没拉到」。
- 查询时一名老师不在该学期：这个人单独列在抽屉顶部「本学期没有课表」，不参与 42 格判定。不能把他当成全程空闲。
